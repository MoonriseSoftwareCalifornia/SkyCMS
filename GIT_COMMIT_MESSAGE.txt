## Architecture Improvements

### Draft/Committed State Pattern
- **Draft**: SETUP/DRAFT_STATE (temporary, session-specific)
  - Created on wizard start
  - Updated as steps are completed
  - Deleted after setup completes
  - Allows resuming incomplete setups

- **Committed**: SYSTEM/SETUP_WIZARD_STATE (permanent)
  - Created after successful completion
  - Marks setup as complete
  - Can be re-run by admins for modifications
  - Stores final configuration with sensitive data cleared

### Security Enhancements
- Sensitive values never appear in HTML (except hidden inputs)
- Client-side masking with reveal functionality
- Audit logs with masked sensitive values
- Per-session draft state (concurrent setups isolated)
- Role-based authorization for post-setup access

### User Experience
- Forward/back navigation throughout wizard
- Step skipping for pre-configured values
- Critical settings warnings on summary page
- Masked display for sensitive connection strings
- Copy-to-clipboard for actual values
