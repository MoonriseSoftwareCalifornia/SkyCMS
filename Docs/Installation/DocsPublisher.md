# SkyCMS Docs Publisher

The SkyCMS.DocsPublisher repository is a standalone template for publishing Markdown documentation to SkyCMS.

## What it is
- A ready-to-clone repo with a `Docs/` tree for Markdown pages
- An importer script under `.skycms/` that syncs docs to SkyCMS
- A GitHub Actions workflow that runs on changes
- Sample content and assets to validate the pipeline

## Where to start
Go to the SkyCMS.DocsPublisher repository for full setup, configuration, and workflow guidance.

## Why this repo exists
SkyCMS can power many sites. This template keeps documentation content separate from the SkyCMS source code, so each site can manage its own docs without cloning the full SkyCMS repository.

## Next steps
- Clone or download SkyCMS.DocsPublisher
- Follow its README and QUICK_START instructions
- Configure repository secrets and run the workflow
