# SkyCMS Editor CSS Customizations Reference

This document describes the custom CSS overrides applied on top of Bootstrap 5 for the SkyCMS editor UI. Use it to understand what must be updated when redesigning the UI to match the product website.

Source CSS: 2024-01-20-01-site.css
Location: Editor/wwwroot/css/

## Scope and conventions
- All overrides are scoped under body.cwps-body to avoid leaking into other pages.
- The editor container uses a dark theme with muted text colors.
- Table styles assume a wide data grid layout (min-width 900px).
- Custom checkboxes use an icon font (icomoon). If the icon font changes, update the checkbox glyph.
- Nested dropdown styles rely on bootstrap-nested-dropdown behavior.

## Typography
Selectors:
- body.cwps-body
- body.cwps-body h1, h2, h3, h4, h5, h6
- .h1, .h2, .h3, .h4, .h5, .h6
- body.cwps-body > p

Current behavior:
- Primary font family is Roboto with system fallbacks.
- Body font weight 300 (light).
- Direct child paragraphs under body.cwps-body use muted gray (#b3b3b3).
- Headings inherit Roboto and keep light weight styling.

Designer notes:
- Replace font-family to match product site typography.
- Review font weights for readability at small sizes.

## Links and transitions
Selectors:

## Custom data table styling
Selectors:
- body.cwps-body .custom-table
- body.cwps-body .custom-table thead tr, .custom-table thead th
- body.cwps-body .custom-table tbody th, .custom-table tbody td
- .custom-table tbody th small, .custom-table tbody td small
- body.cwps-body .custom-table tbody tr:not(.spacer)
- .custom-table tbody tr:not(.spacer):hover
- body.cwps-body .custom-table tbody tr th, .custom-table tbody tr td
- body.cwps-body .custom-table tbody tr th a, .custom-table tbody tr td a
- body.cwps-body .custom-table tbody tr th:first-child, .custom-table tbody tr td:first-child
- body.cwps-body .custom-table tbody tr th:last-child, .custom-table tbody tr td:last-child
- body.cwps-body .custom-table tbody tr.spacer td
- body.cwps-body .custom-table tbody tr.active th, .custom-table tbody tr.active td
- .custom-table tbody tr:hover th, .custom-table tbody tr:hover td
- .custom-table tbody tr.active th a, .custom-table tbody tr.active td a
- .custom-table tbody tr:hover th a, .custom-table tbody tr:hover td a

Current behavior:
- Table background #25252b with a min-width of 900px.
- Headers: white text, no top or bottom borders.
- Cells: white text, light weight (300), 20px vertical padding.
- Secondary text: muted gray (#b3b3b3).
- Rows: rounded corners with hover box shadow.
- Row hover/active: background #2e2e36 and white text.
- Link color in cells: whitesmoke, turns white on hover/active.
- Spacer rows: 3px tall separators with transparent background.

Designer notes:
- Rework table colors, padding, and hover behavior to match product site design tokens.
- Consider responsive table behavior if the product site uses a different grid system.

## Custom checkbox and radio controls
Selectors:
- body.cwps-body .control
- body.cwps-body .control input
- body.cwps-body .control__indicator
- body.cwps-body .control--radio .control__indicator
- body.cwps-body .control:hover input ~ .control__indicator
- .control input:focus ~ .control__indicator
- body.cwps-body .control input:checked ~ .control__indicator
- body.cwps-body .control input:disabled ~ .control__indicator
- body.cwps-body .control__indicator:after
- body.cwps-body .control input:checked ~ .control__indicator:after
- body.cwps-body .control--checkbox .control__indicator:after
- body.cwps-body .control--checkbox input:disabled ~ .control__indicator:after
- body.cwps-body .control--checkbox input:disabled:checked ~ .control__indicator

Current behavior:
- Custom checkbox/radio implementation with hidden input and styled indicator.
- Indicator size 20px, border #3f3f47, background transparent.
- Hover/focus and checked use Bootstrap primary blue (#007bff).
- Disabled state uses light gray (#e6e6e6) with opacity.
- Checked state uses icon font glyph \e5ca from icomoon.

Designer notes:
- If you remove icomoon, replace the checkmark rendering method.
- Update sizes, border radius, and colors to align with product site inputs.

## Nested dropdowns
Selectors:
- .dropdown-menu li
- .dropdown-menu .dropdown-submenu
- .dropdown-menu .dropdown-submenu-left
- .dropdown-menu > li:hover > .dropdown-submenu

Current behavior:
- Submenu appears to the right of parent item; left-aligned variant supported.
- Submenu is shown on hover (display block).
- Layout assumes bootstrap-nested-dropdown pattern.

Designer notes:
- Verify hover-based submenu behavior remains acceptable on touch devices.
- Replace positioning and reveal behavior if product site uses different menu patterns.

## Minimum redesign checklist
- Update typography (font family, sizes, weights) to product site tokens.
- Align colors for backgrounds, text, and interactive states.
- Revisit table density and hover/active treatments.
- Replace or confirm custom checkbox/radio visuals and icon strategy.
- Confirm nested dropdown behavior and positioning.
